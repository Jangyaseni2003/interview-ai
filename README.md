# Interview AI

An AI-powered interview preparation platform. Upload your resume, paste a target job description, and get a full readiness report — a match score, the technical and behavioral questions you're likely to be asked (with the interviewer's intent and a model answer for each), a skill-gap analysis, and a day-by-day prep roadmap. Then practice out loud in a voice-based mock interview that scores your answers, and export an ATS-friendly resume rewritten for that specific job.

**Live:** [interview-ai-red-iota.vercel.app](https://interview-ai-red-iota.vercel.app)

---

## Features

### Interview readiness report
Generated by Google Gemini from your resume and the target job description:
- **Match score** for the specific role
- **Technical & behavioral questions** — each with the interviewer's underlying *intention* and a model answer
- **Skill-gap analysis** — what the role wants that your profile doesn't yet show
- **Preparation roadmap** — a day-by-day plan with individually checkable tasks

All AI output is constrained to a **Zod-defined JSON schema** (via `zod-to-json-schema` and Gemini's `responseSchema`), so responses are structurally guaranteed rather than parsed out of free-form text.

### Voice mock interview
Practice answering out loud:
- Record an answer in the browser, or type it
- Audio is transcribed server-side via Gemini's multimodal input
- The answer is scored out of 100 with written feedback
- Every attempt is saved to the report's history so you can track improvement

### Tailored resume export
Generates an ATS-friendly resume rewritten for the target job — built as HTML, rendered to PDF with Puppeteer, then either downloaded directly or emailed via Nodemailer.

### Section regeneration
Not happy with one part of the report? Regenerate just the skill gaps, just the technical questions, etc. — without re-running (and re-paying for) the entire generation.

### Auth & cost control
- JWT authentication over HTTP-only cookies
- A **token blacklist** collection, so logging out genuinely invalidates the token rather than just clearing the cookie
- A **per-user daily AI quota** with a rolling 24-hour window, so third-party API spend stays bounded

## Tech stack

**Frontend** — React 19, React Router 7, Vite, Sass, Axios

**Backend** — Node.js, Express 5, MongoDB + Mongoose

**AI & documents** — Google Gemini (`@google/genai`), Zod + `zod-to-json-schema` for structured output, Puppeteer (PDF rendering), `pdf-parse` and Mammoth (resume text extraction from PDF/DOCX), Nodemailer

**Auth** — JWT, bcrypt, cookie-parser

## Getting started

### Prerequisites
- Node.js 18+
- MongoDB (local or Atlas)
- A Google Gemini API key

### Backend

```bash
cd Backend
npm install
cp .env.example .env   # then fill in the values below
npm run dev
```

Runs on `http://localhost:3001` by default.

**Environment variables:**

| Variable | Required | Description |
|---|---|---|
| `MONGO_URI` | Yes | MongoDB connection string |
| `JWT_SECRET` | Yes | Long random string for signing tokens |
| `GOOGLE_GENAI_API_KEY` | Yes | Google Gemini API key |
| `PORT` | No | Defaults to `3001`; most hosts inject this |
| `NODE_ENV` | No | Set to `production` when deployed — enables secure/cross-site cookies |
| `FRONTEND_URL` | No | Deployed frontend origin, for CORS. Defaults to `http://localhost:5173` |
| `DAILY_AI_LIMIT` | No | Max AI calls per user per 24h. Defaults to `20` |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASS` / `SMTP_FROM` | No | Real SMTP for emailing resumes. If unset, a temporary Ethereal test inbox is used and a preview link is returned instead of a real email |

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

Runs on `http://localhost:5173`. Set `VITE_API_URL` to point at the backend.

## API overview

All `/api/interview/*` routes and `GET /api/auth/get-me` require authentication via the `token` cookie set on login/register.

### Auth

| Method | Route | Description |
|---|---|---|
| `POST` | `/api/auth/register` | Create an account |
| `POST` | `/api/auth/login` | Log in |
| `GET` | `/api/auth/logout` | Log out (blacklists the current token) |
| `GET` | `/api/auth/get-me` | Get the logged-in user |

### Interview reports

| Method | Route | Description |
|---|---|---|
| `POST` | `/api/interview/` | Generate a report from resume (PDF/DOCX) + job description + self-description |
| `GET` | `/api/interview/` | List the current user's reports |
| `GET` | `/api/interview/report/:interviewId` | Get a single report |
| `PATCH` | `/api/interview/report/:interviewId/section/:section` | Regenerate one section (`technicalQuestions`, `behavioralQuestions`, `skillGaps`, `preparationPlan`) |
| `PATCH` | `/api/interview/report/:interviewId/task/:dayId/:taskId` | Toggle completion of a roadmap task |

### Mock interview

| Method | Route | Description |
|---|---|---|
| `POST` | `/api/interview/report/:id/mock` | Submit an answer, get AI score + feedback |
| `GET` | `/api/interview/report/:id/mock` | List all mock attempts for a report |
| `POST` | `/api/interview/report/:id/mock/transcribe` | Transcribe a recorded spoken answer to text |

### Resume export

| Method | Route | Description |
|---|---|---|
| `POST` | `/api/interview/resume/pdf/:interviewReportId` | Generate and download a tailored resume PDF |
| `POST` | `/api/interview/resume/pdf/:interviewReportId/email` | Generate the PDF and email it to the logged-in user |

Routes that call Gemini (`POST /`, both resume routes, section regeneration, mock submit and transcribe) are behind the daily AI quota middleware and return `429` once a user exceeds `DAILY_AI_LIMIT`.
